# 読みやすいドキュメントの書き方

人に読んでもらう文書を書くとき、または既存の文書を整えるときに従うルールです。読み手がひと目で結論と状態をつかめ、必要なら自分で検証できる文書を目指します。

## 文体

- デスマス調で統一します。
- 簡潔に書きます。前置き、重複、冗長な言い回しを削り、1文を短くします。
- テストの入力文や引用など「データ」は、原文のまま変えません。
- 見出しは h2 を最大にします（Title と h1 は使わない。文書名がタイトルの役割）。小見出しは h3 です。

## レイアウト：内容の形に合わせる

| 内容 | 使う形 |
|---|---|
| 説明、経緯、所見、方法 | 段落（文章） |
| 複数の項目を同じ軸で比べるもの（結果一覧、計画、ログ） | 表 |
| 短い並列項目（質問、依頼、確認事項） | 番号付きリスト |
| 項目ごとに同じ構成で詳しく書くもの | h3 の小見出し＋太字ラベル付きの段落（例：送信文／結果／課題） |

- 箇条書きを説明文の代わりに使いません。箇条書きだらけの文書は読みにくくなります。
- 同じ数字を表と本文の両方に載せません。

## 表

- 見出し行は太字にし、薄い背景色を付け、ヘッダー行を固定します。
- 列幅は内容に合わせます。ID や時刻が途中で折り返さない幅にします。
- 状態は「絵文字＋短いラベル」で書き、表の直前に小さな凡例を置きます。
- セルは短く保ち、説明は本文に回します。

## 絵文字

- 絵文字は、品質や判定の評価をひと目で読ませる箇所にだけ使います。評価の表のセル、その凡例、評価対象ごとの小見出しの判定マークが対象です。
- 見出し、日付、本文のラベル（「送信文：」など）、計画やログの表には付けません。付けすぎると、かえって評価の絵文字が目立たなくなります。
- 状態マーカーは意味を固定して使い、凡例と一致させます。

| 絵文字 | 意味 |
|---|---|
| ✅ | 問題なし、確認できた |
| 🟡 | 軽微、おおむね |
| ❓ | 未確認、裏付けなし |
| 🔺 | 課題あり |
| ❌ | 誤り、失敗 |
| 🔁 | 再現性、揺れ |
| 🔜 | 次に実施 |
| 🟢 | 実施済み |
| ⏳ | 未着手、後で |

- 飾りだけの絵文字は使いません。

## 報告書の書き方（相手に判断してもらう文書）

- 冒頭のサマリーで結論を言います。「良かった点」と「課題」を分けます。
- 事実と推測を分けます。原因の推測は書きません。どうしても書くときは「推測」と明記します。
- 項目ごとに「何を入力したか」「何が返ったか」「課題はあるか（ない場合も『ありません』と明記）」をセットで書きます。
- 相手が自分で検証できるよう、調査の手がかり（ID、時刻、対象、参照すべきフィールド）を表で添えます。
- 計画書には「なぜこの計画になったか（設計の根拠）」を書きます。
- 相談や依頼は番号付きで、相手が答えやすい問いにします。
- 共有前に、トークン、秘密鍵、個人のシークレットなどの機密値が入っていないか確認します。共有設定は作成者自身が行います。

## Google ドキュメントに書くときの注意

Google Docs API（`update_doc`）で書くときの落とし穴です。google-workspace スキルの手順と合わせて使います。

- 全文を書き換えたあとは、箇条書き（`deleteParagraphBullets`）、段落スタイル（`NORMAL_TEXT`）、太字などの文字書式をいったんリセットし、それから見出し・太字・リストを当て直します。直前の段落の書式を引き継いで、全段落が箇条書きになる事故を防ぐためです。
- 日本語や絵文字は、エスケープせずにそのまま渡します。手で Unicode エスケープに書き換えると文字化けします（例：「暫」が「暂」になる）。
- インデックスは UTF-16 単位で数えます。絵文字は2単位以上です。
- 表は google-workspace スキルの `docs_index.py new-table` で作り、複数の表は後ろの位置から順に挿入します。見出し行の色は `updateTableCellStyle`、列幅は `updateTableColumnProperties` で付けます。
- 書いたら必ず読み直して文字を照合し、PDF に書き出して見た目も確認します。

## 仕上げチェック

- [ ] デスマス調で、見出しは h2 まで
- [ ] 説明は段落、一覧は表になっていて、不要な箇条書きがない
- [ ] 表の見出し行に色と太字があり、列が折り返していない
- [ ] 絵文字は評価の箇所だけで、意味が凡例と一致している
- [ ] 推測が事実として書かれていない
- [ ] 文字化けや機密値がない
